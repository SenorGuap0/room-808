SMALL PRINT / GOOD QUESTIONS
Is ROOM 808 a real studio?

No. ROOM 808 is a fictional portfolio project. All rooms, producers, prices, and booking flows are demonstrations.

Can I actually reserve a session?

You can try the booking interface and save a demo reservation on your own device. It doesn't reserve a real studio, process a payment, or check a shared calendar.

Is ECHO really powered by AI?

The GitHub Pages edition uses built-in guided responses. A server-hosted edition can use an AI API when separately configured.
